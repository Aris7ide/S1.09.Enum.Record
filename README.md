# Tasca S1.09 – Enums, Dates i Records

## 📌 Enunciat del exercici
Aquesta tasca recull tres temes fonamentals de Java que t’ajudaran a escriure codi més clar, segur i modern: els enums per representar valors finits i controlats, les dates i hores amb l’API de Java Time per treballar amb el temps de forma robusta, i els records, una novetat de Java per declarar classes de dades immutables amb menys codi.

## ✨ Funcionalitats
- Enums
- Records

## 🛠 Tecnologies
- **Llenguatge**: Java 25
- **IDE**: IntelliJ IDEA
